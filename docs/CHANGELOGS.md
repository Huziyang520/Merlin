### 1.3.1 (2026-11-21)

- Shipped for 1.20.1 (Forge), 26.1 - 26.2 (NeoForge, Fabric) and 26.3 (NeoForge, Fabric).
- New public APIs for dependants: enchanting power scanning, enchantment name and text styling, compat registration, and the evolution rule registry.
- Enchantment name styling is stable within a frame, so mods that match enchantment names against tooltip lines no longer miss them intermittently.
- On 1.20.1 the settings screen is the NeoForge configuration screen (Neo Configuration Screen Port); Cloth Config is no longer used or required.
- On 1.20.1 projectile hits from tridents run the hit hooks again.
- The missing-config-screen notice no longer points at a screen the library does not ship.
